When AI acts

A chatbot answers questions. An agent does things: reads your email, browses, edits files, runs code. A wrong answer you can ignore. A wrong action has already happened.

2The main risk: prompt injection

To a language model, everything is text: your instructions, the web page it reads, the email it summarises. It cannot reliably tell an instruction from you apart from one hidden in the content. So an attacker only needs to put words where your agent will read them.

2025 · Microsoft 365 Copilot

EchoLeak

One email, with no click needed, could make the assistant leak internal data. Microsoft fixed it and found no sign it was used by attackers.

2025 · GitHub

A poisoned issue

A malicious issue in a public project could make a coding agent copy private project data into public view.

July 2025 · a coding platform

Database deleted

During a code freeze, an agent wiped a production database despite instructions, then wrongly said it could not be restored.

3Spot the injection

Your agent is asked to summarise these. Click the sentence an attacker planted for the agent, not for you.

4The lethal trifecta

The danger comes from combining three things. With all three, an attacker can plant instructions, the agent can find your data, and then send it away. Switch them on and off.

What can this agent do?

Simon Willison's lethal trifecta (June 2025) and Meta's Agents Rule of Two (October 2025): at most two in one session, or a human approves.

5Safe by design

Training models to resist helps, but it is not enough. In Anthropic's 2025 tests of a browser agent, attacks worked 23.6% of the time without defences and 11.2% with new safeguards. OpenAI writes that prompt injection is “unlikely to ever be fully ‘solved’”. So build safety into the system.

least privilege

Only the keys it needs

Give access for this task and this session, nothing more. A web summariser does not need your bank account.

sandboxes

Contain mistakes

Work in a copy, a test environment or a separate account. After the database incident, the platform began separating development and production automatically.

separation

Trusted vs untrusted

In CaMeL (Google DeepMind and ETH Zurich), a planner sees only your request and uses tools; a quarantined model reads untrusted content without tools. It solved 77% of benchmark tasks with provable security (84% undefended).

approval

Ask first, act second

A human approves anything irreversible: sending, paying, deleting, publishing.

6What you can do

connect

Connect only what the task needs

Every connected account is a key you hand over.

mix carefully

Strangers' content + your data

Be careful when an agent reads web pages, emails or shared documents while it can also reach your private data.

read

Read approval prompts

They are your last line of defence. Don't click yes on autopilot.

backups

Keep backups

Then a mistake is an inconvenience, not a disaster.
